# Nurba — регуляторный консалтинг

Сайт на React и TypeScript с автономным HTML-предпросмотром. Пять языков:
русский, кыргызский, английский, шведский и норвежский; 32 страницы на каждом.

## Просмотр без установки

Откройте `Предпросмотр.html` в браузере. Страницы находятся в `prototype/`.
Работают навигация, переключение языков, светлая/тёмная тема, поиск,
раскрывающиеся папки услуг и прямые ссылки на WhatsApp, Telegram, телефон и email.
Страница контактов, главная и подвал используют общие контактные данные.

## Запуск React

Требуется Node.js 22.12 или новее.

```sh
npm install
npm run dev
```

```sh
npm run build
```

В текущем окружении Node/npm отсутствовали: установка зависимостей и полный
React production build ещё не проверены. Выполнены экспорт HTML,
проверка локальных ссылок, синтаксиса TSX/JavaScript и отдельные проверки
переключения темы, раскрывающихся списков и статической типографики.

## Структура

- `components/ui/` — переиспользуемые компоненты по структуре shadcn.
- `components/website.tsx` — страницы React.
- `content/site.json` — модель контента для React и HTML.
- `content/contacts.json` — телефон, email и ссылки на мессенджеры.
- `content/service-folder-files.json` — листы в папках услуг на пяти языках.
- `styles/` — Tailwind CSS и стили сайта.
- `lib/` — общий код навигации, темы и визуальных компонентов.
- `public/assets/` — изображения и промпты для созданных изображений.
- `scripts/build_site.py` — генератор и проверка HTML-предпросмотра.

Пересоздать автономную версию:

```sh
python3 scripts/build_site.py
```

Собрать версию для GitHub Pages и проверить основные пути посетителей:

```sh
python3 scripts/build_pages.py
python3 -m unittest discover -s qa
```

Генератор проверяет 161 HTML-файл: локальные переходы, языковые эквиваленты,
уникальность ID и один H1. Код не требует backend для локального просмотра.
Шрифт Jakarta использует внешний CDN; без сети доступен запасной Arial.

## Статус

Это прототип. Переводы требуют языковой проверки. Нет серверного приёма заявок,
CRM, CMS или аналитики. HTML содержит `noindex,nofollow`; настройка рабочего домена,
поисковой индексации и размещения выполняется отдельно.

Сторонние компоненты сохраняют свои авторские уведомления в исходных файлах,
в том числе Glyph Portal © 2026 Christian Katzmann (MIT).
